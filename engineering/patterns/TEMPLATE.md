# Pattern Template

Copy to `patterns/<name>/index.md` and fill. Be honest about trade-offs — a
pattern with no known downsides has no credibility.

## Why we use it
The problem it solves and the trigger conditions.

## When NOT to use it
The cases where this pattern makes things worse. This section is mandatory.

## Trade-offs
- **Advantages:** what it buys you.
- **Disadvantages:** what it costs (complexity, coupling, latency, ops).
- **Alternatives considered:** what else was on the table.

## Vroom examples
Concrete files and how the pattern appears in code.

## Common mistakes
The failure modes people hit when applying it.

## Required tests
The tests that must exist for a compliant use.

## Security review
What a security reviewer must verify for this pattern.

## Performance review
What a performance reviewer must verify for this pattern.
