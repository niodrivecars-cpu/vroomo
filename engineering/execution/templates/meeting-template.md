# Meeting Template

Structured meeting notes that produce decisions and evidence.

## Meta
- Date / attendees / project / purpose

## Decisions needed
1. Decision → options → evidence → outcome (link ADR/RFC if consequential)

## Updates
- What changed since last time, with evidence links

## Blockers
- Blocker → owner → what unblocks it

## Action items
- [ ] Owner: action (due)

## Follow-ups
- Things that need a record: new ADR? RFC? pattern update? pitfall to add to
  `knowledge/`?
