# Vroom Artifacts

Long-lived release and build artifacts for Vroom. Raw run outputs (k6 logs,
verification reports) live in `docs/releases/<version>/`; structured evidence
in `engineering/evidence/`. This directory is for durable artifacts that don't
fit those two locations (e.g. generated reports, diagrams, packaging).

Current: none. See `docs/releases/v1.0.0-rc1/` for RC1 artifacts and
`engineering/evidence/` for the machine-verifiable records.
