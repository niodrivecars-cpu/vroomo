# github MCP

Planned. Covers PR creation, issue triage, and release automation.

## When to use (planned)
- Opening PRs from `release/1.0` to `main` once a remote exists.
- Triaging issues into the roadmap.
- Managing release assets and tags.

## When NOT to use
- Before a remote is configured — this repo has no remote yet.
- For anything better done by hand locally (initial pushes).

## Status
Not configured. Add once a GitHub remote is created and the Push step of the
roadmap is reached.
